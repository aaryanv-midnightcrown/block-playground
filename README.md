# ✦ Pulsecore Studio / Block Playground

A beginner friendly visual playground for exploring how code works! Created with HTML, CSS, and plain JavaScript to let anyone mess around with blocks, control virtual elecs, and peek at real code without any confusion.

---

## Tech Stack & Features

* **Frontend:** HTML5, CSS3, JavaScript
* **Design & Effects:** Dark theme, friendly side photos, and smooth(imo) hover effects
* **Dep Strategy:** Simple single folder website layout

---

## Features

* **'Fun' Digital Playground:** Simple visual controls to flip on lights, change colors, and turn motor arms in real time.
* **Tilted Photo Cards:** Polaroid style pictures on the sides that straighten out when you hover your mouse over them.
* **Easy Block Building:** Click or drag simple blocks to build a fun sequence of actions with zero hassle.
* **Behind the Scenes Code View:** A simple tab that lets you peek at the real C++ code your blocks generate without needing to type a single line.
* **Live Action Log:** A friendly screen box that prints out exactly what your project is doing step by step.
